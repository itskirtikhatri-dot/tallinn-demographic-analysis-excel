Tallinn Population and Ethnicity Analysis Dashboard (2023–2026)
Project Overview

This project analyzes Tallinn's population data from 2023–2026 using Microsoft Excel/WPS Excel.

The dataset includes:
Population by age group
Gender distribution
Ethnic nationalities
Population trends over time

Tools Used
WPS Excel / Microsoft Excel
Pivot Tables
Pivot Charts
Dashboard Design
Data Cleaning

Dashboard Features
Population Trend Analysis
Ethnicity Analysis
Age Group Distribution
Interactive Slicers
KPI Indicators

Key Findings
Estonian population increased from 233,289 to 239,700.
Russian population decreased from 145,323 to 129,105.
Ukrainian population increased from 29,679 to 39,591.
Working-age groups represent the largest share of the population.
